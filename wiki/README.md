# 균균월드 백과사전

공개 열람용 정적 위키입니다.

## 공개 주소
GitHub Pages가 활성화되면 `https://gyungub.github.io/Gyun_World/wiki/` 에서 열람할 수 있습니다.

## 문서 추가
1. `data/documents.json`을 엽니다.
2. 배열 안에 기존 문서와 같은 형식의 객체를 추가합니다.
3. `id`는 영문 소문자와 하이픈으로 고유하게 작성합니다.
4. `status`는 `confirmed`(확정), `proposed`(논의 중), `unknown`(미확정) 중 하나를 사용합니다.
5. 저장하면 공개 사이트에 반영됩니다.

## 열람과 편집 권한
- 사이트 열람은 공개이며 방문자에게 GitHub 계정이 필요하지 않습니다.
- 문서를 저장소에 추가·수정하려면 저장소에 쓰기 권한이 있는 GitHub 계정이 필요합니다.
- 누구나 공개적으로 문서를 읽을 수 있지만, 누구나 무단으로 정사 문서를 수정할 수 있게 하지는 않습니다.

## 정사 관리
논의 중인 아이디어는 `proposed`, 미확인 정보는 `unknown`으로 표시합니다. 창작자 균의 승인 없이 미확정 설정을 확정 설정으로 취급하지 않습니다.
